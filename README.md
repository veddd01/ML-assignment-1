## Quick Start

Clone the repository and open the notebooks with Jupyter:

```bash
git clone https://github.com/veddd01/ML-assignment-1.git
cd ML-assignment-1
pip install jupyter pandas numpy scikit-learn
jupyter notebook
```

Then open the assignment notebook you want to explore. Individual notebooks may require additional packages depending on the techniques used.
